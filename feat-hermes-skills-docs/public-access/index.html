The default shape is LAN-only. STACK_PUBLIC_HOSTS=auto additionally serves the same five services on public names over real TLS, each name composed from the parts you set once. It is purely additive: every LAN route keeps working.

Getting the naming right

scripts/lib/domain.sh owns the grammar and every part is normalized before it is joined, so a value copied out of a browser bar cannot leak into an origin or a server_name:

  • STACK_DOMAIN_BASE (default overeazy.io) is the zone the edge terminates TLS for; STACK_SUBDOMAIN_SUFFIX (default gmktecbeast) is this box's label, shared by every name.
  • STACK_CODER_NAME / STACK_KASM_NAME / STACK_LITELLM_NAME / STACK_HERMES_NAME (defaults coder / kasm / litellm / hermes) are the service prefixes. STACK_DASHBOARD_NAME is empty by default, which puts the dashboard on the zone apex.
  • STACK_ENV_LABEL is empty for the stable stack and sits after the service prefix. Two reasons: the one-label rule below rules the dotted form out anyway, and classify_public_entry in scripts/lib/bootstrap.sh routes an entry by its service prefix, so coder-dev-box.example.com is Coder

    Coder

    The control plane: provisions one Docker container per workspace over the host Docker socket.

     while dev-coder-box.example.com falls through to the dashboard.
  • The shape is load-bearing: each name is one label under the zone, and each service prefix joins it with a hyphen. A wildcard certificate covers exactly one label, so the dotted two-label form (coder.gmktecbeast.) has no certificate at the public edge: the browser aborts with ERR_SSL_VERSION_OR_CIPHER_MISMATCH and Traefik

    Traefik

    The reverse proxy that terminates TLS for the public names.

     never sees the request. Measured on this box - coder-gmktecbeast.overeazy.io completes the handshake with the zone's *.overeazy.io cert, while the dotted form fails with a TLS alert 40 and presents no certificate at all.

STACK_PUBLIC_HOSTS has three states, and only the middle one composes:

  • empty is LAN-only;
  • auto composes the five names from the parts above;
  • a comma-separated list is used verbatim, which is how you pin a name by hand (leave STACK_PUBLIC_HOSTS_MODE empty, or that key keeps re-deriving).

A part that cannot be a DNS label composes nothing: that service is left out of the list rather than sent as an empty entry, and a missing zone keeps the whole stack LAN-only.

What bootstrap changes when the names are set

bazelisk run //scripts:bootstrap derives:

  • STACK_DASHBOARD_URL, which compose feeds to HOMEPAGE_EXTERNAL_URL so NextAuth builds its redirects and Secure cookie from the public origin;
  • STACK_CODER_URL / STACK_KASM_URL / STACK_LITELLM_URL / STACK_HERMES_URL, the card hrefs. A hermes-* or hermes.* entry is what fills STACK_HERMES_URL. Compose copies that value into HERMES_DASHBOARD_PUBLIC_URL, the Host and Origin the Chat tab checks;
  • an upgraded CODER_ACCESS_URL (the public coder name);
  • an extended HOMEPAGE_ALLOWED_HOSTS - homepage validates the incoming Host against that exact-match list, so an unlisted name fails its host check;
  • a Coder

    Coder

    The control plane: provisions one Docker container per workspace over the host Docker socket.

     certificate whose DNS SANs now carry the public names alongside the existing ones. The LAN cert keeps working; in public mode the browser never sees it, since Traefik

    Traefik

    The reverse proxy that terminates TLS for the public names.

     presents real ones;
  • STACK_PUBLIC_HOSTS_MODE=auto, which records that the names are derived. Under auto the parts are the source of truth and STACK_PUBLIC_HOSTS is output only, so a list edited by hand there is ignored and bootstrap prints a note: naming the key to clear. It clears itself on the LAN-only and explicit-list paths;
  • the router's vhost table: proxy/router.conf.template is rendered into proxy/router.gen.conf (gitignored) and STACK_ROUTER_CONF=router.gen.conf is written, because compose mounts ./proxy/${STACK_ROUTER_CONF:-router.conf}. The warn_missing_router_hosts check runs against that rendered file, so a name the table does not answer is reported before the recreate rather than as a 421 after it.

Set the naming parts in .env and put auto in STACK_PUBLIC_HOSTS (.env.sample documents every part and shows the explicit-list shape beside it), and in dev-stack.env too when a dev stack runs beside the stable one. Then re-run bootstrap and recreate the stack you switched. The commands are in the README.
