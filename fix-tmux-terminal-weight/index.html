evo-t1-coder-stack

One compose stack that turns a GMKtec EVO-T1 into a self-hosted dev-workspace server — Coder, LiteLLM, IPEX-LLM Ollama, Kasm, Homepage and Hermes.

What's on this page

  • What runs on the box and which door each service answers on
  • Where to start depending on what you came to do
  • How the sidebar tabs divide the subjects

What this enables

  • Getting oriented in one screen before opening a terminal
  • Reaching the page that owns a subject from one card, instead of reading four that touch it

This repository brings up one Compose project on a GMKtec EVO-T1 (Intel Core Ultra 9 285H, Arc 140T iGPU, 96 GB DDR5) and keeps it runnable by conversation, by dashboard, or by bazelisk. Everything is a Bazel

Bazel

The hermetic build and test system every operator CLI is a target of.

 target addressed as bazelisk run //scripts:<stem> -- <args>. On the stack host, scripts/setup-host.sh is the one script meant to run straight from a shell. On a laptop, reopen the repo in the contributor environment or run bazelisk run //scripts:test-in-image.

The box deliberately runs two isolated copies of the stack: a stable one you work in and a dev one you break. Two stacks on one box in the README is the short version; docs/config-updates.md covers what a git pull leaves behind.
