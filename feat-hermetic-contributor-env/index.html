evo-t1-coder-stack

One compose stack that turns a GMKtec EVO-T1 into a self-hosted dev-workspace server — Coder, LiteLLM, IPEX-LLM Ollama, Kasm, Homepage and Hermes.

What's on this page

  • What runs on the box and which door each service answers on
  • Where to start depending on what you came to do
  • How the sidebar tabs divide the subjects

What this enables

  • Getting oriented in one screen before opening a terminal
  • Reaching the page that owns a subject from one card, instead of reading four that touch it

This repository brings up one Compose project on a GMKtec EVO-T1 (Intel Core Ultra 9 285H, Arc 140T iGPU, 96 GB DDR5) and keeps it runnable by conversation, by dashboard, or by bazelisk. Everything is a Bazel target addressed as bazelisk run //scripts:<stem> -- <args>. On the stack host, scripts/setup-host.sh is the one script meant to run straight from a shell. On a laptop, reopen the repo in the contributor environment or run bazelisk run //scripts:test-in-image.

The box deliberately runs two isolated copies of the stack: a stable one you work in and a dev one you break. Two stacks on one box in the README is the short version; docs/config-updates.md covers what a git pull leaves behind.

What runs here

ServiceHost portWhat it is for
Homepage (+ nginx sidecar)80 / 443The landing page, and the only thing publishing it
Coder3001Control plane: one container per workspace
Coder agent tunnel3002The plain listener a workspace agent dials via host.docker.internal
LiteLLM4000The single OpenAI-compatible door in front of every model
IPEX-LLM Ollama—The Arc 140T model runtime, never published to the host
Kasm3000 → 4443Streamed desktops; the wizard only on first boot
Hermes9119The host assistant. LAN :9119 stays; the public name is opt-in via STACK_PUBLIC_HOSTS
SearXNG8181Keyless metasearch, the fallback search lane

Ollama is reachable only from inside the compose network: LiteLLM is the gateway, and it is the thing that carries the master key.

The sidebar tabs divide the rest: Learn covers how the pieces work, Operate covers running the box day to day, and Contribute covers the gates a change runs through. Each subject has exactly one page, and the README links to that page rather than repeating it.
