# Infisical managed-key inventory -- the one list of the stack's secret surface.
#
# Syntax is one KEY per line; a '#' comment or a blank line is all else.
# infisical_managed_keys() in scripts/lib/infisical.sh reads it with
# `grep -E '^[A-Z0-9_]+$'` and nothing else, so the banners below are
# documentation of who consumes each group, never structure a parser sees.
#
# Every key must also exist in .env.example: Infisical feeds .env on a pull and
# compose keeps interpolating .env, so a key missing there is a key no service
# ever receives. The first 8 are the list scripts/bootstrap.sh used to carry
# twice; that list and any new one is this file.

# Coder: the coder service's PostgreSQL URL and the db container's password.
CODER_PG_PASSWORD

# LiteLLM: the master key every agent lane authenticates with.
LITELLM_MASTER_KEY

# Homepage: the dashboard auth secret and the basic-auth password.
HOMEPAGE_AUTH_SECRET
HOMEPAGE_AUTH_PASSWORD

# Hermes: basic-auth on the dashboard, plus the API server key the agents call with.
HERMES_DASHBOARD_PASSWORD
HERMES_DASHBOARD_SECRET
HERMES_API_SERVER_KEY

# Grafana: the observability admin login.
GRAFANA_ADMIN_PASSWORD

# SearXNG: the signing secret, handed to the searxng service as SEARXNG_SECRET.
STACK_SEARCH_SECRET_KEY

# LiteLLM upstream: the per-box key for each of the three Spark inference hosts.
SPARK_1_API_KEY
SPARK_2_API_KEY
SPARK_3_API_KEY
