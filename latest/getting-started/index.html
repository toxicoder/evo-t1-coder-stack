Getting started

First boot on a GMKtec EVO-T1, top to bottom — bootstrap the host, bring the stable stack up, register Coder, push the templates, open a workspace.

What's on this page

  • The one-time host bootstrap, and why it is the only step run straight from a shell
  • Bringing the stable stack up and pulling the models
  • Registering the first Coder account, pushing both templates, wiring the chat agent
  • Creating the first workspace from a git URL

What this enables

  • A working stack on a fresh box without reading the whole README first
  • Knowing which step to re-run when a later one says a prerequisite is missing

The commands are the README's spin-up section with the reasoning attached. Run them on the stack host, not inside a workspace: a workspace's docker addresses its own DinD sidecar, and the whole-stack targets reach the daemon that runs Coder.

Before you start

  • A GMKtec EVO-T1 (or any box with the Arc 140T and enough RAM for the model in OLLAMA_MODELS) with Docker and Compose v2 installed.
  • The LAN address you will browse to. CODER_ACCESS_URL has to be an https:// URL that is not localhost, or a workspace cannot reach LiteLLM.
